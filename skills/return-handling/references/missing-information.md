# 缺失信息询问指引

先核对当前用户已经提供的信息，不重复询问已有的明确内容。订单事实由工具查询，适用政策由知识检索核实。

- 缺订单号时，请用户提供订单号；不要根据旧会话猜测当前订单。
- 有订单号但缺具体原因时，询问商品出现的现象，或用户希望退货的具体原因。“质量问题”不足以推断具体故障。
- 用户暂时说不清原因时，可以请其描述使用中观察到的情况；不要列举某个故障并当成用户已确认。
- 日期、商品状态等条件影响判断时，先查询能取得的事实，再只询问尚缺的条件。
- 信息不足时，不生成退货预览或声称已受理。简要列明已知信息、待补充项；已有执行计划时将对应步骤标记 blocked，等待用户回复。

参考文件只说明如何询问，不提供订单、退货资格或实时政策的证据。
