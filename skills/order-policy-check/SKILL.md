# 订单与政策核对

1. 明确订单号和问题，缺订单号时询问；仅问通用政策无需查订单。
2. 发现 get_order、search_knowledge，获取订单事实和政策原文。本技能不提供实时事实。独立查询可并行或委派 orders、knowledge；只交接必要信息。
3. 核对状态、时间、商品和适用条件，区分用户陈述、工具事实与待确认项。来源冲突时重新核对或说明不确定性。
4. 根据失败反馈调整查询；无新证据时换词、缩小范围、询问或停止，不重复空转。
5. 回答先给判断，再给依据和缺失信息；未经实际操作不能声称已提交。要办理申请可加载 return-handling，仍遵守审批与确认。

遇到来源冲突或适用条件不明确时，可单独调用 read_skill_resource 读取[冲突与缺失条件核对指引](references/evidence-check.md)，普通订单查询无需读取。
